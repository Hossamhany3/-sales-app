🔗 رابط إعادة التوجيه (redirect URI) المطلوب تسجيله في Google Cloud:
🛠️ خطوات إصلاح الربط
  1. افتح التطبيق من الإنترنت (GitHub Pages) وليس كملف محلي — الربط لا يعمل من file://.
  2. إذا ظهر خطأ invalid_client فالـ Client ID الحالي محذوف/غير صحيح: ادخل إلى Google Cloud Console → APIs & Services → Credentials → Create Credentials → OAuth client ID → اختر Web application.
  3. في خانة Authorized JavaScript origins أضف: https://hossamhany3.github.io وفي خانة Authorized redirect URIs أضف رابط إعادة التوجيه أعلاه بالضبط.
  4. انسخ الـ Client ID الجديد والصقه في خانة «🆔 معرّف تطبيق OAuth» أعلاه ثم اضغط «💾 حفظ».
  5. من OAuth consent screen — إذا كان في وضع Testing أضف بريدك كـ Test user، أو انقل التطبيق إلى Production.
  6. ثم اضغط زر «🔗 ربط بحساب Google» مرة أخرى.
